# MAGSTA MTG

MTGニュース・大会情報・5chまとめ・新カード情報をまとめるサイト。

## 運営方針
- 最新情報はRSS等から収集し、重複を整理する
- 日本語記事と英語記事を分けて表示する
- 英語記事には日本語要約を付ける
- 今日のピックアップカードは日替わりで更新する
- 自動更新は人間による確認を前提にする

## 継続更新の優先順位
1. 毎日のピックアップ更新安定化
2. RSSタイムラインの取得・表示安定化
3. 最新記事と記事一覧の連携整理
4. モバイル表示・メニュー導線の改善
5. GitHub Actionsによる定期更新基盤の整備

## 曜日別編集サイクル
- 月：週間ニュース
- 火：フォーマット別メタゲーム
- 水：今週の注目カード
- 木：市場・カード動向
- 金：週末注目情報
- 土：大会・デッキ速報
- 日：今週のMAGSTAまとめ

### 共通フォーマット
Standard / Pioneer / Modern / Legacy / Vintage / Commander / Pauper

各記事では、確認できた事実とMAGSTA編集部の考察・予測を分離し、関連記事へ相互リンクする。
